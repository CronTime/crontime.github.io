CronTime

The modern task scheduler for macOS. Replace Unix cron with a native SwiftUI app that lets you create, manage, and monitor scheduled jobs—shell commands or web automation—through an intuitive visual interface.

Visual Schedule Builder

No more editing crontab files or memorizing syntax. Use preset buttons for common schedules like every minute, hourly, daily, or weekly. Custom time pickers offer precise control, with real-time descriptions and advanced cron editing when needed.

Web Automation Engine

Go beyond shell commands. Automate web tasks with WKWebView: fill forms, click elements, run JavaScript, capture screenshots. Schedule interactions without manual scripting.

Template Library

Start fast with 30+ pre-built templates for backups, monitoring, cleanup, security scans, and more. Customize them easily as the foundation for your jobs.

Siri and Shortcuts Integration

Control jobs by voice or from Shortcuts. Run tasks, check status, enable or disable—with seamless macOS integration.

Real-Time Monitoring

Track job execution, logs, and status in one place. Built for reliability, with improvements in version 1.1.4 for better localization and performance.

FAQ

Does CronTime replace the system's cron?

Yes, it fully replaces Unix cron with a visual, native macOS alternative. No terminal required.

Can I automate websites?

Absolutely. The Web Automation Engine handles form filling, clicks, JavaScript, and screenshots via WKWebView.

What about advanced users?

Advanced mode lets you edit cron syntax directly while keeping the visual builder.
